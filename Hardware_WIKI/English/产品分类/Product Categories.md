# Product Categories

This overview organises 48 standard product types into six groups by primary function. Start with what the part needs to do—guide a strap, connect, close, decorate or mount—then use photographs, a drawing or a sample to identify the form. The final specification should still confirm the dimensions, materials, installation method and functional requirements.

## Browse by function

- Buckles, Rings & Adjusters — components that guide, join or adjust straps and webbing.
- Hooks & Spring Connectors — quick-attachment components with a hook, gate or spring action.
- Locks & Closures — components that close, retain or release an assembly.
- Decorative & Branding Hardware — visible identifiers, pendants and ornamental parts.
- Mounting, Fastening & Small Hardware — parts that attach, reinforce, protect or finish an edge.
- Chains, Packaging & Special Hardware — linked, packaging-related and project-specific items.

## How to choose a category

Start with the user action: adjust, connect, lock, decorate or mount. Then confirm the visible structure—such as a fixed bar, tongue, spring gate, magnet, screw or mounting leg—and how it attaches to the main product. Similar outlines can serve different functions, so an image alone cannot confirm moving, magnetic or locking performance.

## Choose by the job

If the item guides or adjusts a strap, start with buckles and rings. If it clips on and off, start with hooks and spring connectors. If it closes a bag or case, start with locks and closures. If its primary purpose is visual, start with decorative and branding hardware. If it attaches, reinforces or protects, start with mounting and small hardware. Linked, packaging-related and unusual shapes belong in the special-hardware group.

## 数字化经验分享

这里记录我在工厂数字化、业务系统建设，以及 AI 工具落地过程中的经验与方法，希望把实际工作中的思考整理成便于阅读、交流和复用的文字。

内容从具体业务问题出发，关注流程如何梳理、系统如何连接、权限如何管理，以及如何确认开发结果真正符合业务需要。

本仓库以 Markdown 文本为主，部分内容提供中英对照，适合工厂管理人员、业务系统开发者，以及关注制造业数字化的读者。

## Sharing Digitalization Experience

This repository shares lessons and practical methods from factory digitalization, business system development, and the use of AI tools in everyday work. The aim is to turn experience into written material that is easy to read, discuss, and reuse.

The content starts with business problems: understanding workflows, connecting systems, managing permissions, and checking whether development results meet real business needs.

The repository primarily contains Markdown documents, with selected material presented in both Chinese and English. It is intended for factory managers, business application developers, and readers interested in manufacturing digitalization.

Read [Digitalization Experience: Nine Topics](Factory_Digitalization/README.md). The nine articles share the same level and can be read independently.

### Reading Notes

- Read the documents directly on GitHub or download them for use in a Markdown editor. No website framework is required.
- Adapt the shared experience to your own workflows, architecture, and operating conditions.
- Manufacturing, inspection, and testing articles are educational references. Actual production and release decisions must follow applicable standards, customer requirements, and controlled documents.
- Tool articles contain textual explanations only. This repository does not include the corresponding online tools, website applications, or image assets.

Questions, corrections, and suggestions for future topics are welcome through Issues.

# Golden Luck Hardware Knowledge

## Start with a practical question

Use this Wiki to identify a hardware part, compare familiar forms, or explain a drawing or sample to a colleague. Product pages show what a part looks like, where it is commonly used, what to compare, and which similar names can cause confusion.

If you already have a drawing or local CAD file, the tools section offers a quick AQL reference and a browser-based viewer for an initial file check. These are reference aids, not replacements for an approved drawing, sample, inspection plan or specification.

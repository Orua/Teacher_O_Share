# CAD Drawing and 3D Model Viewer

This viewer is for buyers, project coordinators and new team members who need an initial view of a local drawing before requesting a formal engineering review. Supported formats include DWG, DXF, STL, STEP/STP, IGES/IGS and BREP/BRP.

For 3D models, the right-side finish selector can preview Light Gold, Nickel, 24K Gold, Gunmetal, four lower-gloss matte variants, Antique Brass and Antique Silver. The visual treatment applies to the dominant/base component while other exported component colours are preserved. Antique finishes use a seamless reference texture in the browser; they are for appearance discussion only, not a plating specification, approved colour or production acceptance standard.

### Three simple steps

1. Choose a local file in a supported format.
2. Pan, zoom and fit the view to inspect the overall shape and visible details.
3. Record questions and return to the approved source drawing for any production decision.

> **Technology trial:** This is a browser-viewing experiment for testing and reference. It is not recommended for commercial use or as the basis for production approval.

## What the viewer can help with

Open a supplied drawing, then pan, zoom and fit the view to review the overall geometry and visible details. The viewer supports early communication, file checks and discussion before a formal engineering review. It does not change the source file or replace approved drawings, samples and specifications.

## Privacy and practical limits

Files selected from your computer are processed locally in the browser and are not uploaded by the viewer. A local-file history entry stores only the file name, not the file itself or its original path. Proxy objects, external images and uncommon custom CAD entities may not render correctly. Use the approved source drawing for production decisions.

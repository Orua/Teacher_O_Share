# AQL Quick Reference

This quick reference is for buyers, inspectors and production personnel who use sampling tables. Enter the lot size, inspection level and AQL value; the browser then displays the sample-size code, sample size, acceptance number (Ac) and rejection number (Re). The lookup uses a public sampling data table in the browser.

## How to use the result

1. Choose the production lot size, inspection level and AQL value from the controlled inspection plan.
2. Read the returned code and sample size, then inspect that number of pieces.
3. Compare the observed defect count with Ac and Re before recording the result.

The result is a quick reference for the sampling table used by this tool. It does not select the appropriate inspection level or AQL for a product. Confirm the controlled inspection plan, contract, customer requirements and any critical-defect rules before release. Ac means the lot may be accepted when the observed defect count does not exceed that number; Re means the lot is rejected when the count reaches that number.
